Two printers learning together without sharing data

Each site runs its own agents and keeps its raw measurements. Only small belief summaries cross between sites. We compare three setups on the same plates: isolated (own data only), networked (own data plus the other site's messages) and oracle (all raw data pooled, the upper bound).

Prediction error by round

Scored on held-out pieces no agent chose. Lower error and higher log predictive density are better. Oracle gap closed is how much of the isolated-to-oracle gap the network closes (1 = as good as pooling raw data).

Agents at the site

Agents propose pieces and bid with credibility. Credibility goes up when an agent's pieces improve held-out predictions. Before the bids clear, agents can flag each other's proposals, and each flag is checked on held-out data after printing.

Across the boundary

The only thing that leaves a site is a message with shared-parameter summaries, agent credibility and unmet needs. Each site weights incoming messages by how much they have helped its own held-out predictions.
